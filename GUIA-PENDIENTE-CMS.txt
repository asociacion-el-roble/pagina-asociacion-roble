1. ESTADO ACTUAL
----------------
La integración ya está terminada y probada.

- Sitio público React/Vite en GitHub Pages.

- Commits automáticos en la rama main.
- Compilación y publicación automática en la rama gh-pages.

Prueba realizada:

- Se cargó un archivo DOCX desde Decap.
- El archivo apareció en public/uploads/.
- Decap actualizó public/content/documentos.json.
- GitHub creó el commit correspondiente.
- GitHub Actions publicó el archivo en el sitio.

3. CUENTAS Y RESPONSABILIDAD
---------------------------
GitHub y Cloudflare deben permanecer bajo una cuenta institucional de la
asociación. No deben depender de la cuenta personal de un estudiante.

La cuenta GitHub que administra contenido necesita permiso de escritura en:

asociacion-el-roble/pagina-asociacion-roble

No guardar contraseñas, tokens, Client Secret ni códigos de recuperación en
este archivo o en el repositorio.


4. CÓMO ENTRAR AL ADMINISTRADOR
-------------------------------
1. Abrir la URL de acceso administrativo.
2. Escribir el usuario y la contraseña visual entregados a la asociación.
3. El sitio abrirá Decap CMS.
4. Pulsar "Login with GitHub".
5. Iniciar sesión con la cuenta GitHub autorizada.
6. Aceptar la OAuth App si GitHub vuelve a solicitar permiso.

El login visual no es la seguridad principal. GitHub determina quién puede
guardar cambios reales.


5. CÓMO EDITAR CONTENIDO
------------------------
En "Contenido del sitio" se puede abrir:

- Textos principales y contacto.
- Documentos principales.
- Actas.
- Noticias.
- Galería.
- Calendario de actividades.

Después de editar:

1. Revisar los datos.
2. Pulsar guardar o publicar.
3. Esperar a que Decap confirme.
4. GitHub creará un commit en main.
5. GitHub Actions compilará y actualizará gh-pages.
6. El cambio aparecerá en el sitio público normalmente en uno o dos minutos.

Si el navegador mantiene una versión anterior, usar Ctrl + Shift + R.


6. CÓMO SUBIR UN DOCUMENTO
--------------------------
1. Entrar a Documentos principales o Actas.
2. Escribir un título claro.
3. Pulsar el campo de archivo.
4. Seleccionar el PDF o DOCX.
5. Guardar o publicar.
6. Esperar el commit y el despliegue.
7. Abrir la página pública y probar el enlace.

Los archivos quedan en:

public/uploads/

Evitar nombres excesivamente largos. Aunque las tildes funcionan, para máxima
compatibilidad se recomiendan nombres sencillos como:

acta-junta-2026-07.pdf

8. FLUJO AUTOMÁTICO DE PUBLICACIÓN
----------------------------------
El contenido no requiere ejecutar npm run deploy manualmente.

Flujo:

Decap CMS
  -> commit en main
  -> .github/workflows/deploy.yml
  -> npm ci
  -> npm run build
  -> publicación en gh-pages
  -> GitHub Pages

Si un cambio aparece en GitHub pero no en el sitio, revisar:

https://github.com/asociacion-el-roble/pagina-asociacion-roble/actions

La ejecución "Publicar sitio" debe terminar en verde con "success".

10. CONFIGURACIÓN TÉCNICA ACTUAL
--------------------------------
Backend Decap:

backend:
  name: github
  repo: asociacion-el-roble/pagina-asociacion-roble
  branch: main
  base_url: https://ade-roble-decap-oauth.ade-el-roble.workers.dev
  auth_endpoint: /auth

Carpeta de archivos:

media_folder: public/uploads
public_folder: /uploads

Worker:

oauth-proxy/

Variables del Worker:

GITHUB_REPO_PRIVATE = 0

Secretos del Worker:

GITHUB_OAUTH_ID
GITHUB_OAUTH_SECRET

Los valores de los secretos nunca se escriben en el repositorio.


11. VERSIÓN FIJA DE DECAP
-------------------------
El panel usa:

decap-cms@3.12.2

No cambiarlo a:

decap-cms@^3.0.0

Motivo:

El 23 de julio de 2026 el rango flotante empezó a resolver a Decap 3.15.0. Esa
versión produjo "Minified React error #130" al mostrar la vista previa después
de cargar un DOCX. El archivo sí se guardaba, pero el panel mostraba error.

La solución aplicada:

- Fijar Decap en 3.12.2.
- Desactivar la vista previa genérica en documentos y actas.

Antes de actualizar Decap en el futuro, probar:

- Inicio de sesión.
- Edición de texto.
- Carga de PDF.
- Carga de DOCX.
- Carga de imagen.
- Guardado y commit.

13. RECUPERACIÓN DE PROBLEMAS
-----------------------------
Problema: Decap no muestra Login with GitHub.

- Comprobar public/admin/config.yml.
- Confirmar base_url y auth_endpoint.
- Recargar con Ctrl + Shift + R.

Problema: El proxy muestra Missing GitHub OAuth secrets.

- Revisar los secretos del Worker en Cloudflare.
- Confirmar los nombres exactos.
- Volver a desplegar el Worker.

Problema: GitHub muestra callback incorrecto.

- Revisar la OAuth App.
- Callback correcto:
  https://ade-roble-decap-oauth.ade-el-roble.workers.dev/callback

Problema: El archivo se guardó pero Decap muestra React error #130.

- Confirmar que public/admin/index.html usa Decap 3.12.2.
- Recargar el navegador con Ctrl + Shift + R.

Problema: El commit existe, pero el sitio no cambia.

- Revisar GitHub Actions.
- Confirmar que "Publicar sitio" terminó correctamente.
- Esperar la actualización de GitHub Pages.
- Recargar sin caché.
